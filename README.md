# Roundel Sim Club — Website Concept

Website mockup for a fictional sim racing bar in Columbus, OH. Styled after a race-car livery: blue panels, tri-colour pinstripes, number roundels and pit boards.

**Live:** https://thinkfirstjason.github.io/roundel-sim-club/

- Single static `index.html`, no build step
- Design language for reuse: [DESIGN.md](DESIGN.md)
- Photos from [Unsplash](https://unsplash.com) (Unsplash License)

Fictional business. Names, addresses and phone numbers are made up.
